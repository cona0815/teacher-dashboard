# 教師工作台介面美術：Codex 交接手冊（三套可切換風格）

> 給 Codex 的工作說明，請整份讀完再動手。
> 分工：**Codex 畫圖、交圖**。把圖接到網頁、做風格切換、改程式、改測試由 Claude 處理。
> 小綿助桌寵不在這次範圍，系統美術也**不可以**用小綿助的角色或畫風。

## 1. 為什麼要做

教師工作台現在的圖混了三家外部素材，風格不統一，也不是我們自己的：

| 現在用的 | 在哪裡 | 數量 |
|---|---|---|
| いらすとや（日本插圖） | 晨間大屏「大屏提示」「安靜偵測」 | 12 張 |
| IP as Logo 吉祥物圖示 | 晨間大屏分頁、工作台摘要卡與面板 | 14 個 |
| Koboyo 圖示 | 工作台身分切換、Board.html | 5 個 |
| 表情符號 emoji | 晨間大屏「班級工具」8 個圖磚 | 8 個 |

這次全部換成原創美術。老師要能在**三套風格**之間切換，同一個位置的圖跟著整套換掉。

## 2. 三套風格（`art_spec.json` 的 `themes`）

| id | 名稱 | 感覺 | 人物 |
|---|---|---|---|
| tech | 科技 | 未來教室、資訊看板：深藍夜色、青與紫的霓虹光、玻璃質感 | 無五官的圓頭全息人偶 |
| minimal | 簡潔 | 像交通標誌與瑞士海報：白底、大量留白、一眼看懂、零裝飾 | pictogram 圓頭人形 |
| cozy | 可愛溫暖風 | 悠閒田園生活的手作溫暖感：奶油、草綠、天空藍、木頭棕，像貼紙或繪本 | 原創 Q 版學生（2.5 頭身） |

每套的完整定義在 `themes[]`，都要照著畫：
- `palette`：底色、文字色、主色，以及五個分類色。
- `icon`：圖示畫法。
- `illustration`：插圖畫法。
- `figure`：人物造型。
- `avoid`：禁忌。

這份色票也是之後網頁介面的配色，Claude 會用同一份做切換，所以**圖裡的顏色要用色票裡的顏色**。

### 各風格的畫法重點

- **科技**：
  - 圖示：等粗圓角線條（256px 畫布約 10px）＋外圍柔和光暈；光暈拿掉後剪影仍然認得出來。
  - 插圖：等角視角的光滑 3D 場景，半透明玻璃加發光邊，少量粒子。
  - 不要寫實照片感、電路板花紋、綠字雨。
- **簡潔**：
  - 圖示：雙色調，幾何線條（256px 畫布約 21px、圓角轉折）＋一塊淡色填色。
  - 插圖：扁平幾何，只用 2–3 色，不陰影、不漸層、不描邊、不加裝飾小物。
- **可愛溫暖風**：
  - 圖示：圓胖實心物件，深棕粗描邊（約 12px）、柔和高光、外圍白邊像貼紙。
  - 插圖：手繪繪本感，柔和水彩紋理、圓潤輪廓，點綴草地、小花、空白木牌。
  - **這是「風格」不是同人圖**。不可出現下列任何東西，也不要畫成動物村民：
    - 任天堂或《集合啦！動物森友會》的角色。
    - 葉子標誌、NookPhone。
    - 遊戲字型或介面元件。

## 3. 要交的圖（清單在 `art_spec.json`）

每一套風格都要畫一整套，三套共 **183 張**：

| 類別 | 每套數量 | 用在哪裡 | 網頁版尺寸 |
|---|---:|---|---|
| prompt 大屏提示插圖 | 23 | 每一句班級提示一張，外加自訂提示的預設圖 | 960×720 |
| quiet 安靜偵測 | 4 | 超安靜、安靜、有點吵、太吵 | 800×800 |
| icon 介面圖示 | 34 | 大屏分頁、班級工具圖磚、工作台摘要卡、面板標題、身分 | 256×256 |

每張在 `art_spec.json` 都寫好了：
- `id`：檔名。
- 提示文字或用途。
- `category`：分類，決定主色。
- `scene`／`subject`：畫面內容。

三套風格裡**同一個 id 畫的是同一件事**，只有畫風不同。請照著畫，不要自己換主題。

## 4. 共通規定（`art_spec.json` 的 `style`）

- **不可以出現小綿助家族**（綿羊、橘貓、薩摩耶、藍白機器人）或任何像牠們的角色。
- **同一套裡要像同一個設計師畫的**：線條粗細、顏色、光源、人物比例都一致。
- **人物**照各風格的 `figure`：
  - 學生男女都有，穿一般便服或運動服。
  - 不畫特定學校的制服或校徽。
- **圖裡不能有任何文字、數字、字母、商標**，系統會在圖上方顯示大字。
  - 倒數用圓燈表示。
  - 臂章、木牌都空白。
  - 廁所門用水滴圖示。
  - 「LINE 收件匣」不可用 LINE 商標。
- **透明背景**：不畫整片背景；圖示不要畫底色方塊，系統會自己加圓角色塊。
- **示範正確行為**：quiet_loud 是唯一的錯誤示範，不要畫危險動作。
- **台灣國小教室的物件**：單人課桌椅、聯絡簿、不鏽鋼分格餐盤、掃把畚箕、樓梯扶手。
- **分類主色**用該風格 `palette` 裡的顏色：
  - order：上課秩序
  - study：作業與學習
  - life：生活作息
  - move：集合與移動
  - alert：太吵

### 三種圖各自的重點

- **prompt 大屏提示**：
  - 投影到教室電視，教室後排 8 公尺外要一眼看懂。
  - 主角要大、動作要清楚、細節少。
  - 主體落在畫布 6%–94%。
- **quiet 安靜偵測**：單一人物（quiet_loud 例外）、表情強烈；系統會加漂浮或搖晃動畫。
- **icon 介面圖示**：
  - 實際只顯示 22–80px，一個主物件、剪影清楚，縮到 22px 還認得出來。
  - 主體置中、落在 8%–92%。
  - 身分圖示（role_*）才畫人物半身。

## 5. 技術規格

| 項目 | prompt | quiet | icon |
|---|---|---|---|
| 原始大圖（PNG） | 1920×1440 | 1600×1600 | 1024×1024 |
| 網頁版（WebP、透明） | 960×720 | 800×800 | 256×256 |
| 網頁版檔案上限 | 160KB | 120KB | 30KB |
| 安全範圍 | 6%–94% | 6%–94% | 8%–92% |

- 網頁版：`assets/art/<風格>/<類別>/<id>.webp`，例如 `assets/art/cozy/prompt/focus_teacher.webp`。
- 原始大圖：`assets/art/_masters/<風格>/<類別>/<id>.png`，不 commit，已列入 .gitignore。
- 邊緣保留抗鋸齒（半透明像素），不要硬邊去背。
- 可以用影像生成工具。每套風格先定好一張「風格基準圖」，之後每張都附上它當參考，確保整套一致。
- 生出來的圖要自己檢查，有任何一項不對就重生：
  - 有沒有字、有沒有多出的手腳。
  - 像不像小綿助或任天堂角色。

## 6. 自我檢查（交件前必做）

```bash
pip install pillow
python assets/art/check_art.py --review
```

- 每一項都要是 **PASS** 或 **WARN**，不能有 **FAIL**。WARN 要在交件說明裡解釋。
- 檢查會擋下：
  - 缺檔、尺寸不對、不是 WebP、沒透明。
  - 四個角不透明（畫了底色方塊）。
  - 主體貼邊、檔案太大。
- 打開 `assets/art/_review/` 用眼睛看：

| 預覽檔 | 看什麼 |
|---|---|
| `compare_themes.png` | 同一張圖三套風格並排，看是不是畫同一件事、三套有沒有明顯區別 |
| `<風格>/icons.png` | 圖示在 22／32／48／96px、該風格的淺底與深底上的樣子；22px 認不出來的要重畫 |
| `<風格>/prompt_<id>.jpg` | 模擬投影全螢幕（大字在上、圖在下、該風格的底色），想像在教室後排看 |
| `<風格>/prompts.png`、`<風格>/quiet.png` | 整套是否一致、四個安靜狀態一眼分得出來 |

## 7. 交件順序（先定風格，再量產）

1. **第一批樣本**：只畫 `art_spec.json` 的 `first_batch` 那 8 張，三套風格都畫，共 24 張：
   - 2 張大屏提示、1 張安靜偵測。
   - 4 個圖示、1 個身分圖示。
   - 跑 `python assets/art/check_art.py --first-batch --review`，把 `_review/` 的圖給老師看。
   - **老師確認三套風格都對了才繼續。**
2. **第二批**：其餘全部。可以一次一套風格交。

## 8. 交件方式

1. 從 `main` 開分支 `codex/ui-art-v1`。
   - 用 `git worktree` 另開資料夾做，不要動到目前工作資料夾裡小綿助分支還沒 commit 的檔案。
2. 只新增 `assets/art/<風格>/` 底下的 webp 檔；`_masters/` 與 `_review/` 不要 commit。
3. 寫 `assets/art/DELIVERY.md`，內容包括：
   - 每套風格的風格基準圖是哪一張、用了什麼工具。
   - 每張圖一行：檢查結果、備註。
   - check_art.py 的完整輸出。
   - 你覺得哪幾張還可以更好。
4. commit 訊息寫 `教師工作台介面美術（Codex 交件，第 N 批）`。
5. 不要 push 到 main、不要合併、不要打 tag。
