# 教師工作台介面美術：Codex 交接手冊

> 給 Codex 的工作說明，請整份讀完再動手。
> 分工：**Codex 畫圖、交圖**。把圖接到網頁、改程式、改測試由 Claude 處理。
> 小綿助桌寵動畫不在這次範圍。

## 1. 為什麼要做

教師工作台現在的圖混了三家外部素材，風格不統一，也不是我們自己的：

| 現在用的 | 在哪裡 | 數量 |
|---|---|---|
| いらすとや（日本插圖） | 晨間大屏「大屏提示」「安靜偵測」 | 12 張 |
| IP as Logo 吉祥物圖示 | 晨間大屏分頁、工作台摘要卡與面板 | 14 個 |
| Koboyo 圖示 | 工作台身分切換、Board.html | 5 個 |
| 表情符號 emoji | 晨間大屏「班級工具」8 個圖磚 | 8 個 |

這次全部換成**小綿助家族**的原創美術，和老師的桌寵同一套角色、同一種畫風。

## 2. 要交的圖（清單在 `art_spec.json`）

| 類別 | 數量 | 用在哪裡 | 網頁版尺寸 |
|---|---:|---|---|
| prompt 大屏提示插圖 | 23 | 每一句班級提示一張，外加自訂提示的預設圖 | 960×720 |
| quiet 安靜偵測角色 | 4 | 超安靜、安靜、有點吵、太吵四個狀態 | 800×800 |

每一張在 `art_spec.json` 都寫好了：

- 分類強調色 `accent`

**請照著畫，不要自己換主題。**

## 3. 畫風（`art_spec.json` 的 `style`，硬規定）

- **角色只用小綿助家族四隻**，外表一律照 `assets/pet/v4/reference/<角色>/` 的正式美術：
  - lamb：小綿羊，主角。
  - cat：橘虎斑貓。
  - dog：薩摩耶。
  - robot：藍白懸浮機器人，螢幕臉，沒有腳。
  - 三隻動物都戴青綠色項圈＋雪花獎牌，配色、頭身比不能變。
- **不畫人類**：沒有學生、沒有老師人物，四隻角色就是班上的學生。
- **筆觸**照 reference：
  - 柔和漸層陰影、毛絨毛邊。
  - 暖棕色描邊，不是黑線。
  - 腮紅、眼睛兩點高光。
- **透明背景**：只畫角色和必要道具（課桌、樓梯），地上一個柔和橢圓影子，不畫整片背景。
- **圖裡不能有任何文字、數字、字母、商標**，系統會在圖上方顯示大字。
  - 倒數用圓燈表示、組長臂章不寫字、廁所門用水滴圖示。
  - 「LINE 收件匣」不可用 LINE 商標。
- **示範正確行為**：quiet_loud 是唯一的錯誤示範，不要畫危險動作。
- **台灣國小教室**：單人課桌椅、聯絡簿、不鏽鋼分格餐盤、掃把畚箕、樓梯扶手。
- **光源**統一在左上。
- **分類強調色**只用在道具和光暈，角色本身的顏色不變：
  - 上課秩序：綠 `#1f7a52`
  - 作業與學習：藍 `#2457e6`
  - 生活作息：橘 `#d0631a`
  - 集合與移動：紫 `#7b4fb8`

### 三種圖各自的重點

- **prompt 大屏提示**：
  - 投影到教室電視，教室後排 8 公尺外要一眼看懂動作。
  - 主角要大、動作要誇張清楚，細節少一點。
  - 主體落在畫布 6%–94%。
- **quiet 安靜偵測**：
  - 單一角色（quiet_loud 例外）、正面、表情強烈。
  - 系統會加漂浮或搖晃動畫，角色本身擺好姿勢就好。
- **icon 介面圖示**：
  - 實際只顯示 22–80px：一個主物件、輪廓粗、剪影清楚，縮到 22px 還認得出來。
  - 物件可以有小小的臉（點點眼＋腮紅），但不要細節雜訊。
  - **不要畫底色方塊**，系統會自己加圓角色塊。
  - 主體置中、落在 8%–92%。
  - 身分圖示（role_*）才用角色半身。

## 4. 技術規格

| 項目 | prompt | quiet | icon |
|---|---|---|---|
| 原始大圖（PNG） | 1920×1440 | 1600×1600 | 1024×1024 |
| 網頁版（WebP、透明） | 960×720 | 800×800 | 256×256 |
| 網頁版檔案上限 | 160KB | 120KB | 30KB |
| 安全範圍 | 6%–94% | 6%–94% | 8%–92% |

- **網頁版**：`assets/art/<類別>/<id>.webp`，例如 `assets/art/prompt/focus_teacher.webp`。
- **原始大圖**：`assets/art/_masters/<類別>/<id>.png`，不 commit，已列入 .gitignore。
- 邊緣保留抗鋸齒（半透明像素），不要硬邊去背。

## 5. 怎麼畫

- 可以用影像生成工具。生成時一定要附上 `assets/pet/v4/reference/` 的角色圖當參考，讓角色長得一模一樣。
- 生出來的圖要自己檢查角色，有任何一項不對就重生：
  - 臉型、項圈、配色、robot 的螢幕臉。
  - 有沒有多出的手腳、有沒有字。
- 去背後再縮成網頁版。
- 同一隻角色在 23 張插圖裡要像同一隻，不能這張胖、那張瘦。

## 6. 自我檢查（交件前必做）

```bash
pip install pillow
python assets/art/check_art.py --review
```

- 每一項都要是 **PASS** 或 **WARN**，不能有 **FAIL**。WARN 要在交件說明裡解釋。
- 檢查會擋下：
  - 缺檔、尺寸不對、不是 WebP、沒透明。
  - 四個角不透明（畫了底色方塊）。
  - 主體貼邊、檔案太大。
- 打開 `assets/art/_review/` 用眼睛看：
  - `icons.png`：每個圖示在 22／32／48／96px、淺底和深底的樣子。22px 認不出來的要重畫。
  - `prompts.png`：全部插圖的總覽，看四隻角色是不是一致。
  - `prompt_<id>.jpg`：模擬投影全螢幕（大字在上、圖在下），想像在教室後排看。
  - `quiet.png`：四個狀態排在一起，情緒要一眼分得出來。

## 8. 交件方式

1. 從 `main` 開分支 `codex/ui-art-v1`。
   - 建議用 `git worktree` 另開資料夾，不要動到目前工作資料夾裡小綿助分支還沒 commit 的檔案。

3. 寫 `assets/art/DELIVERY.md`，內容包括：
   - 每張圖一行：檢查結果、備註。
   - 用了什麼工具生成、參考了哪幾張 reference。
   - check_art.py 的完整輸出。
   - 你覺得哪幾張還可以更好。
4. commit 訊息寫 `教師工作台介面美術（Codex 交件，第 N 批）`。
5. 不要 push 到 main、不要合併、不要打 tag。
