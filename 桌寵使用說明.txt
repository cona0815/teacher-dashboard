小綿助桌寵｜方案一（Python 原始檔版）

一、安裝需求
1. Windows 10／11
2. Python 3.10 以上：https://www.python.org/downloads/
3. 在本資料夾開啟 PowerShell，執行：

   py -m pip install -r requirements.txt

二、啟動完整桌面秘書
雙擊「啟動小綿助秘書.bat」。
如果沒有畫面，請在 PowerShell 執行：

   py desktop_pet_secretary.py

三、只看動畫測試
雙擊「開啟小綿助桌面預覽.bat」，或執行：

   py desktop_pet_preview.py

左鍵點一下會顯示一句打氣話，拖曳可移動；右鍵選單可開啟秘書首頁、測試動畫或關閉桌寵。秘書首頁內可自訂名稱，以及 1～120 分鐘的打氣間隔，預設每 5 分鐘出現一次。

四、快速交代測試
點桌寵開啟秘書首頁，在「快速交代」輸入內容，按「交給小綿助整理」，確認草稿後再按「確認建立本機任務」。
文字框支援 Ctrl+V 貼上圖片或複製的檔案，也可以按「圖片／檔案」選取附件。小綿助會使用 Windows OCR 讀取圖片文字，並可抽取 TXT、PDF、Word、Excel、PowerPoint 的文字後再整理。

五、資料位置
桌寵資料會保存在：

   %APPDATA%\XiaoMianZhuSecretary\

記事與桌寵任務保存在 secretary_data.json，附件保存在 attachments 資料夾。預設不會出現在網頁系統；若在首頁設定 GAS /exec 網址與同步金鑰，可同步任務。記事可手動匯出給網頁，原始附件不會自動上傳。

六、健康管理
1. 喝水：按「喝一杯」，今日累計會以水滴圖示顯示。
2. 起身活動：可從下拉選單設定提醒間隔，預設 60 分鐘；進度條會每秒累計，時間到由小綿助提醒。
3. 服藥：從下拉選單選擇時間後按「新增時間」，可設定多筆；每一筆時間到由小綿助提醒，並可分別標記已服用。

此方案預設是離線本機版，不會強迫連到 Google。需要任務同步時，才在小綿助首頁選填 GAS /exec 網址與同步金鑰；連線失敗時仍保留本機資料。
