🐣 超級新手設定教學

完全不懂電腦也沒關係。照著做，一步打一個勾，大約 5 分鐘就能在教室開始用晨間大屏。

完成 0 步

開始之前，先放心三件事

  • 不用安裝任何東西。它就是一個網頁，像看新聞一樣打開就好。
  • 不用申請帳號、不用花錢。第一關什麼都不用申請。
  • 按錯不會壞。真的弄亂了，照這頁重做一次就好。

你只需要準備

  • 教室那台接著大電視（或投影機）的電腦，而且連得上網路。
  • 電腦裡的 Chrome（圓圓的紅黃綠藍圖示）或 Edge（藍綠色海浪圖示）。兩個都可以，學校電腦一定有其中一個。
  • 知道你們班最後一號是幾號、哪幾號沒有人（空號）。
📌 這套系統有五關，只做第一關就能用。後面的關卡想用再做，不做也完全沒關係。
關卡做完可以…要多久
🟢 第一關教室大屏：點名、收作業、黑板聯絡本、抽籤、計時5 分鐘
🔵 第二關在家用手機／電腦寫聯絡本，隔天自動出現在大屏20 分鐘
🟡 第三關請 AI 幫忙整理訊息、寫草稿3 分鐘
🟠🟣 第四、五關LINE 小幫手、桌面小幫手（進階，看完整教學）30 分鐘以上

看不懂的字，先看這裡

這個字白話意思
網址網頁的「地址」，一串英文，通常是 https 開頭。
點一下滑鼠移過去，按左邊那顆鍵一次。觸控大電視就用手指碰一下。
分頁畫面上方那一排按鈕（點名、作業繳交…），點哪個就換到哪一頁。
複製／貼上複製：先選起來，按 Ctrl＋C。貼上：點一下要放的格子，按 Ctrl＋V。
找字畫面字太多找不到某一格？按 Ctrl＋F，打要找的字（例如「空號」），畫面會自動跳到那裡。
重新整理按鍵盤最上面一排的 F5，網頁會重新載入一次。
金鑰一長串亂碼，就是「密碼」。第二關才會用到。
本機就是「這台電腦」。資料存本機＝只放在這台電腦裡，不會傳出去。

🟢 第一關：把教室大屏設定好

一共 8 步。每做完一步，就在那一步的方框打勾。

請在教室那台電腦上，點下面這顆綠色按鈕。

👉 點我打開晨間大屏

左邊一格一格的座號（1、2、3…），右邊一塊綠色黑板。

⭐ 順便把它存起來，以後不用再找：在大屏那一頁按 Ctrl＋D，再按 完成。以後打開瀏覽器，上方就有它。

看畫面上方那一排按鈕，最右邊那一顆叫 設定，點它一下。

這個密碼是防學生亂改用的。第 7 步會教你換成自己的。

一整頁的設定格子。不用每一格都填，只要找到下面這 3 格。

  1. 班級名稱：點一下格子，打你們班，例如 601。
  2. 班級最大座號：往下捲一點就看到。打你們班最後一號，例如最後一號是 26 號，就打 26。
  3. 空號：就在「班級最大座號」旁邊。中間有沒有人的座號才要填，用「、」隔開，例如 4、13。沒有空號就不用填。

找不到？按 Ctrl＋F 打「最大座號」就會跳過去。如果有看到「我教的班級」這一格，留空不用填。字體、風格、顏色那些格子也先不用管。

🔒 這裡只用座號，不用、也請不要打學生姓名。

繼續往下捲，找到 科目管理 這幾個字。

每個科目是一顆小按鈕：深綠色有打勾＝會出現，白色＝不出現。點一下就可以切換。

示意圖
國語 ✓數學 ✓英語 ✓生活音樂聯絡簿 ✓
😌 不確定就先不要動，預設的國語、數學、英語、自然、社會、聯絡簿、通知單已經夠用。下面一大片「作業項目」也一樣，之後用到再回來點亮就好。

再往下捲過一大片作業項目，會看到兩個時間：

格子預設意思
遲到界線08:00這個時間以後才點「到校」的，系統偷偷記成遲到（大屏上不會寫出來，孩子看不到）。
自動缺席08:05到這個時間還沒點的座號，自動變成「未到」。

跟你們學校的時間一樣就不用改。不一樣就點格子改成你們的時間。

找到寫著 設定頁密碼（預設 1234，請改成只有您知道的） 的格子（可能在最上面，也可能在下面；按 Ctrl＋F 打「設定頁密碼」最快）。點一下格子，把裡面的黑點全部刪掉，打一個你記得住、學生猜不到的密碼。

✏️ 請現在把新密碼寫在你的教師手冊裡。忘記的話看最下面「卡住了」。

再往下找到「💾 資料要存在哪裡？」——確認左邊 💻 只存在這台電腦（本機） 前面的圓圈是選起來的（預設就是，通常不用動）。

捲到最下面，點深綠色的 儲存設定。

示意圖
儲存設定
☝ 沒按這顆，前面填的都不算

檢查有沒有成功

  1. 點上方最左邊的 點名。座號是不是到你填的最後一號？空號是不是不見了？
  2. 點一下 1 號。它變成綠色的「到校」，就是成功了。再多點幾下會輪流變成 病假 → 事假 → 未到 → 未填。
  3. 按鍵盤 F5。畫面閃一下之後，1 號如果還是剛剛的樣子，代表資料有存住。
🎉 第一關完成！明天早上就可以用了。

☀️ 每天怎麼用（只要會這四件事）

要做的事怎麼做
點名學生進教室，自己點自己的座號一下，變綠色「到校」。請假的由老師多點幾下，換成病假或事假。
寫聯絡本在「點名」那一頁右邊的黑板上方，點 ✏️ 編輯，直接打字，打完按儲存。字太小就按 字＋。
收作業點上方 作業繳交 → 選科目和作業 → 新增。交了的學生點自己的座號。
計時右上角點 5分 或 10分，再點 開始。

抽籤機、計分板、隨機分組、番茄鐘…都在上方的 班級工具 裡，有空點進去玩玩看，不會壞。

⚠️ 第一關的資料只存在這台電腦的這個瀏覽器，保留 180 天。換電腦、換瀏覽器（Chrome 換 Edge）、或請人「清除瀏覽紀錄」，舊紀錄就看不到了。想要換電腦也看得到，請做第二關。

想要電腦一開機就自動打開大屏？看完整教學第 1 級最後一段。

🔵 第二關：在家也能寫聯絡本（想要再做）

做完之後：晚上在家用手機或電腦寫好聯絡本，隔天早上大屏自動出現；點名和缺交紀錄也會自動存到你自己的 Google 雲端。

⏱ 這一關要 20 分鐘，步驟比較多，請找一段不會被打斷的時間，用電腦做（不要用手機）。需要一個 Google 帳號（就是 Gmail）。建議用自己的 Gmail，學校帳號有時候會被擋。

先印出（或抄下）這張小卡

過程中會拿到三樣東西，拿到就貼進記事本，或抄在這裡：

🌐A 機器人網址 🔑B 大屏金鑰 🔑C 工作台金鑰

💡 不知道記事本在哪？按鍵盤左下角的 ⊞ Win 鍵，打「記事本」三個字，按 Enter。

點這顆按鈕（要你登入 Google 就先登入）：

👉 建立我的副本

一個寫著「複製文件」的畫面，中間有藍色按鈕 建立副本。點它。

等幾秒，會開出一張像 Excel 的表格。這張表格是你自己的，別人看不到。

在表格上方的選單列（檔案、編輯、查看…那一排）的最右邊，等大約 10 秒，會多出一個 🤖 LINE 小幫手。

  1. 點 🤖 LINE 小幫手 → 點 ① 初始化。
  2. 跳出「需要授權」→ 點 確定（或「繼續」）。
  3. 選你的 Google 帳號。
  4. 會看到一個嚇人的畫面「Google 尚未驗證這個應用程式」。這是正常的！因為這份程式是你自己的副本，不是 Google 商店的產品。
  5. 點左下角小小的 進階 → 再點最下面的 前往…（不安全）。
  6. 把 選取全部 打勾 → 捲到最下面點 繼續。
  7. 授權完，要回到表格「再點一次」：🤖 LINE 小幫手 → ① 初始化。
跳出一個視窗，上面有兩串亂碼：🔑B 和 🔑C。

把這兩串分別複製，貼到記事本，前面註明哪個是 B、哪個是 C。

沒看到「🤖 LINE 小幫手」？按 F5 重新整理，再等 10 秒。

「部署」聽起來很難，其實只是「請 Google 給這張表格一個網址」。照著點就好：

  1. 表格上方選單點 擴充功能 → Apps Script。會開一個滿滿英文程式的新分頁，裡面什麼都不要改。
  2. 右上角點藍色的 部署 → 新增部署作業。
  3. 左邊「選取類型」旁邊有個 ⚙ 齒輪，點它 → 選 網頁應用程式。
  4. 「執行身分」選 我。
  5. 「誰可以存取」選 任何人（一定要選這個，不然大屏連不上。別擔心，沒有金鑰的人進不來）。
  6. 點右下角 部署。
  7. 出現「網頁應用程式」下面一長串網址，結尾是 /exec。點旁邊的 複製。

把它貼到記事本，註明「🌐A」。然後點 完成，這個滿滿英文的分頁可以關掉了。

  1. 打開晨間大屏 → 最右邊 設定 → 輸入你的密碼。
  2. 捲到下面，點一下藍色那一條 🔵 第 2 級：連上工作台，它會打開。
  3. 網址那一格貼上 🌐A；金鑰那一格貼上 🔑B。
  4. 上面一點的「💾 資料要存在哪裡？」改選右邊 ☁️ 存到雲端。
  5. 最下面點 儲存設定。
右上角出現「☁️ 自動存雲端」的小標籤。之後每 5 分鐘自動存一次，不用管它。

工作台是老師自己用的那一頁（在家、在辦公室、用手機都可以開）：

👉 打開教師工作台

  1. 右上角點 ⚙ 設定。
  2. 視窗上方點 ① 雲端／LINE 小幫手。
  3. 把「啟用雲端同步」打勾。
  4. 「🌐A」那一格貼上 🌐A；「🔑C」那一格貼上 🔑C。
  5. 點 測試連線。看到成功的訊息 → 點 立即同步 → 最後點 儲存設定。
🎉 第二關完成！在家那台電腦或手機，也照這一步做一次（貼同樣的 🌐A 和 🔑C），就能在家寫聯絡本了。

在家寫聯絡本

  1. 工作台中間的「教師工具箱」點 聯絡本。
  2. 日期選明天，用下拉選單加項目（例如「作業」→「國習」→ 補充欄打「p.20」→ ＋ 加入）。
  3. 按 💾 儲存到雲端。明天早上大屏一打開，黑板就有了。

💡 想一次看整個月寫了什麼，按日期那一列最左邊的 📅 日曆，點任何一天就能修改（按 ✏️ 單日 回來）。右邊黑板上方的 直橫・間距 可以換直書、調字距和行距。

🔐 🔑B、🔑C 等於你家鑰匙，不要傳到群組、不要貼在公開的地方。

每一步都想看更細的圖解，請看完整教學第 2 級。

🟡 第三關：加上 AI（想要再做，3 分鐘）

  1. 打開 Google AI Studio 的金鑰頁，用 Google 帳號登入。
  2. 點 Create API key（建立 API 金鑰）。
  3. 出現一長串亂碼 → 點複製，貼到記事本，註明「🔑D」。
  1. 打開教師工作台 → 右上角 ⚙ 設定 → 上方點 ② AI 設定。
  2. 在「🔑D API 金鑰」那一格貼上。
  3. 點 取得清單，模型選名字裡有 flash 的（比較快、免費額度多）。
  4. 點 儲存設定。
🔒 用 AI 時，請不要把學生的全名、身分證字號、電話貼進去。

第四關（LINE）和第五關（桌面小幫手）比較進階，請看完整教學。

🆘 卡住了？先看這裡

遇到的狀況怎麼辦
密碼打 1234 進不去確認是數字、沒有多打空白，鍵盤右邊數字鍵沒反應的話按一下 Num Lock。
忘記自己改的密碼只能把這台瀏覽器裡「這個網站的資料」清掉，密碼會回到 1234，但設定要重填、存在這台電腦的紀錄也會一起不見。不會清的話請資訊組長幫忙。所以密碼請一定要抄下來。
填好的設定不見了多半是忘了按最下面的 儲存設定，或是換了瀏覽器（上次用 Chrome，這次用 Edge）。請固定用同一個。
昨天的點名不見了正常！大屏每天早上都是全新的一天。舊紀錄在 查詢統計 裡（要做第二關才有）。
字太小，後面看不到按住 Ctrl 再按 ＋ 可以把整個畫面放大；黑板的字用 字＋。按 F11 可以全螢幕。
第二關：選單沒有「🤖 LINE 小幫手」按 F5，等 10 秒。還是沒有，代表開到的不是你複製的那一份，請重做第二關第 1 步。
第二關：測試連線失敗九成是這三種：① 🌐A 結尾不是 /exec（複製錯了）② 部署時「誰可以存取」沒選「任何人」③ 🔑B 和 🔑C 貼反了——大屏用 B，工作台用 C。
學校帳號說「無法存取」學校的 Google 帳號擋住了。請改用自己的 Gmail 重做第二關。

還是不行？把畫面拍照，拿給資訊組長或給你這個網址的老師看，比用講的快。
