第 3 關：接上 LINE（Webhook）

1

省事法（推薦）：試算表選單「📋 更新安裝總表」→ 點最前面的「📋 安裝總表」分頁 → 🔗 那一列的「值」就是拼好的網址，點那一格複製。

https://script.google.com/macros/s/AKfy…很長一串…/exec?hook=a1b2c3d4e5…
2
🟩 網站①｜Developers Console → 你的 channel →「Messaging API」分頁 → 往下找「Webhook settings」→ Webhook URL 旁「Edit」→ 貼上 →「Update」。
✔ 檢查：儲存後網址結尾看得到 ?hook=（欄位太窄時點進去按 End 鍵看結尾）。
3
🟩 網站①｜同一區把「Use webhook」撥成開啟（變綠色）。
按「Verify」若跳「302 Found」是正常的，按 OK 關掉——Google 網址會先轉址一次，LINE 的檢查鈕不吃轉址所以誤報，以下一步的手機實測為準。
4
🎉 見證時刻：用手機對機器人傳「我的ID」→ 它會回一串 U 開頭的字。有回話就是全線打通了！
沒回話？最常見三個原因：①網址拼錯 ②「Use webhook」沒開 ③「自動回應訊息」沒關（第 1 關第 7 步②）。

第 4 關：鎖門（只聽你的話）

1
手機上長按機器人回的那串 U 開頭的字 →「複製」→ 用 LINE 電腦版或傳給自己的 Email 帶到電腦（或直接在電腦版 LINE 複製）→ 試算表選單「③ 填入我的 LINE userId（鎖門）」→ 貼上 → 確定。
還沒鎖門前，第 2 版的機器人不會執行任何指令，只會回你的 userId 請你填——避免陌生人加好友就能指揮你的班級系統。

📢 LINE 額度怎麼算？
LINE 免費方案的則數只算「小幫手主動推播」；你問它答完全免費、無上限。
會用到額度的只有：點名推播、作業推播、未點名提醒、週五家長關懷，以及預設關閉的 每日簡報備援、早期缺交預警、到期前一天提醒、放學小結。
在 LINE 傳「推播設定」可看到 8 項開關與本月真實用量（這也是安裝或更新後的驗收指令）， 傳「開啟 放學小結」「關閉 作業推播」即可切換。 用量接近上限時，系統會自動只保留點名推播，不會突然爆量。
⚠️ 額度是按收件人計算：若把兩支手機或同事的 ID 都加進 LINE_ALLOWED_USER_IDS，用量會加倍。
☁️ LINE 檔案自動備份（解決檔案過期）
傳給小幫手的照片與檔案（含轉傳的），會在收到當下自動存進你自己的 Google 雲端硬碟， 回覆訊息裡附上連結。以後 LINE 對話裡的檔案過期也不怕。
而且會自動分類命名：AI 讀完內容後，把檔案改成看得懂的名字，並歸到對應資料夾—— LINE小幫手備份／2026-08／會議與晨會／0828_第二次返校日晨會報告事項.jpg
分類有：通知單與回條、學生與親師、會議與晨會、公文與行政、課程與教材、活動與競賽、其他。
試算表會多一個「檔案備份」分頁當索引；在 LINE 傳「找檔案 晨會」就能找出檔案與連結。

🔐 備份與安全

  • ☁️ 雲端備份（做了難度 1 才有）：工作台「設定 → 備份與還原 → 立即雲端備份」，整份存進你自己的試算表（「工作台備份」分頁），保留最近 10 份，預設每天開啟工作台時自動備份。換電腦時「查看雲端備份 → 還原這份」。
  • 每週一次：「設定 → 備份與還原 → 下載 JSON 備份」（不含金鑰，可安心存隨身碟），不依賴任何服務的離線保險。
  • ⚠️ 工作台的任務與教學進度平常只存在「這台電腦的這個瀏覽器」。試算表裡的「工作台快照」只是給 LINE 簡報用的摘要，不是備份、不能還原；能還原的只有上面兩種。
  • 金鑰的家：你的金鑰記錄表；🔑B🔑C🔑D 也能在試算表選單「🔑 顯示我的金鑰」再看；🔑E 在 Google AI Studio；🔑A 在 LINE Developers。金鑰與 🌐 不要貼到公開網頁或群組。
  • 權限分層：教室電腦只放 🔑D（只能回報當天）；🔑C（老師金鑰，可查歷史）只放自己的電腦。
  • 試算表就是雲端紀錄：點名、作業、聯絡本的歷史都在你自己 Google 帳號的試算表裡。
  • 大屏只使用座號，不輸入學生姓名；遲到紀錄只有老師在 LINE 與統計看得到。

升級三步驟（原網址、原金鑰、原資料通通不變）

  1. 網站免更新：網頁版會自動是最新版，按 Ctrl+F5 重新整理就好。
  2. 更新雲端大腦程式（有做難度 1 的老師才要做）：
    1. 開你的試算表 → 擴充功能 → Apps Script
    2. 按這顆按鈕取得最新程式碼：

      網站上的最新 LineBot.gs 版本：讀取中…（跟你的「ℹ️ 程式版本」比，舊了才要更新；一樣就不用動）
      （若按鈕失敗，可開啟原始碼後 Ctrl+A 全選、Ctrl+C 複製）
    3. 回 Apps Script：點進程式碼區 → Ctrl+A 全選 → Ctrl+V 貼上（會直接蓋掉舊的）→ 按 💾 儲存（不應出現紅色錯誤）
    4. 部署 → 管理部署 → ✏️ 編輯 → 版本選「新版本」→ 部署（⚠️ 千萬不要按「新增部署」，網址會變）
  3. 重新授權一次（正常現象，不是壞掉）：第 2 版多了「建立表單、寄信、圖文選單、寫入 Google 日曆、存檔到雲端硬碟」等能力，第一次使用這些新功能時 Google 會再跳一次授權——照難度 1 授權圖允許並勾「選取全部」，只會問這一次。
🐑 有裝小綿助的老師：關掉舊版（工作列右下角小綿羊圖示按右鍵結束，或工作管理員結束 XiaoMianZhu.exe）→ 下載新版 ZIP 解壓覆蓋舊資料夾（記事與設定在 %APPDATA%\XiaoMianZhuSecretary，不受影響）→ 打開新版，照小綿助第 4、5 步設定。
🔒 第 2 版的保護機制：如果還沒用選單③填 userId，機器人不會執行任何指令，只會回你的 userId 請你填——貼進選單③就通了。
🧹 從很舊的版本升上來？如果曾遇到「同一天點名被記很多筆」，升級後按選單「🤖 LINE 小幫手 → 🧹 清理重複資料（修統計）」一次。
