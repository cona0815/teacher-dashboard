📖 安裝教學（新手版）

從零開始，一步一步把「教師工作台＋LINE 小幫手＋晨間大屏」全部設定好。照著做就會，不需要任何程式基礎。

先看這裡 A. 工作台 B. LINE 小幫手 C. 晨間大屏 D. 每天怎麼用 E. 疑難排解 F. 備份與安全 版權

🧭 先看這裡：整套系統有三層，用多少裝多少

層級要裝什麼能做什麼
① 工作台網頁什麼都不用裝，開網址就能用任務清單、日曆、教學進度排課、記事、JSON 備份
② 晨間大屏需要先完成 B（因為要雲端同步）教室電腦點名、收作業、黑板聯絡本、統計報表
③ LINE 小幫手照本頁 B 部分部署一次（約 40–60 分鐘，只做一次）LINE 傳文字／語音／照片建任務、寫聯絡本、每日簡報、家長訊息草稿
會用到的名詞（先有個印象就好）：
・Google 試算表＝像 Excel 的雲端表格，當作 LINE 訊息的「轉運倉庫」。
・Apps Script（GAS）＝Google 提供的免費小程式空間，我們把「機器人的大腦」貼進去。
・金鑰＝一長串亂碼，功能像鑰匙：拿到鑰匙的人才能開門。本系統共有 4 把＋1 個網址，全部用下面的符號標記。
🗝 符號對照表（超重要！設定畫面的欄位上印著一模一樣的符號，照著貼就對了）：
符號這是什麼哪裡取得貼到哪裡
🔑AChannel access tokenPart B 第 1 關，LINE Developers 按 Issue 發行Apps Script「指令碼屬性」的 LINE_CHANNEL_ACCESS_TOKEN（第 3 關）
🔑BWebhook 驗證參數Part B 第 2 關，執行 setupLineBot 後的「執行紀錄」（隨時可再執行查看）接在機器人網址後面：🌐?hook=🔑B（第 5 關）
🔑C工作台同步金鑰（老師專用，可查歷史）工作台「⚙ 設定 → LINE 小幫手 → 🔑C 同步金鑰」欄；大屏「查詢統計」也用這把
🔑D教室大屏金鑰（教室專用，只能報當天）大屏「⚙ 設定 → 🔑D 教室大屏金鑰」欄（教室電腦只放這把）
🌐機器人網址（/exec 結尾）Part B 第 4 關，部署後產生的網頁應用程式 URL工作台與大屏的「🌐 Apps Script 部署網址」欄，以及第 5 關的 Webhook URL
💰 費用：全部免費。LINE 官方帳號免費方案＋Google 免費額度就夠用。唯一的量限制：LINE「主動推播」每月 200 則（每日簡報一天 1 則，一個月才用 30 則，很夠）。

🅰 Part A：開始使用工作台（3 分鐘）

1
打開工作台網址，加入書籤
（載入中…）

開啟後按 Ctrl＋D 加入書籤，以後一鍵開啟。

2
填基本資料

右上「⚙ 設定 → 教師資訊」：填姓名職稱、按「＋新增課程」把任教課程一門一門加進去（例如「六年一班社會」）。

不用登入、資料不上雲端；但換電腦或換瀏覽器就看不到資料。所以：定期到「設定 → 備份與還原 → 下載 JSON 備份」，換電腦時用備份檔還原。

✅ 到這裡，任務、日曆、教學進度已經全部可用。想要 LINE 與大屏，繼續 Part B。

🅱 Part B：部署 LINE 小幫手（40–60 分鐘，一生只做一次）

做完這部分，你會擁有一個「只聽你的話」的 LINE 機器人。過程有 7 關，每一關都很短。

第 1 關：建立 LINE 官方帳號（＝機器人的身體）

1
用電腦開 developers.line.biz/console，點「Log in with LINE account」，用你手機 LINE 的帳號密碼登入（手機 LINE →設定→帳號 可以確認/設定 Email 登入）。
2
按「Create a new provider」，名稱隨便打（例：我的教師工具）→ Create。
3
按「Create a Messaging API channel」。若它要求先建官方帳號：到 manager.line.biz 建立（免費），名稱例如「班級小幫手」，建好後進該帳號「設定 → Messaging API」按啟用，再回來。
4
進入 channel 的「Messaging API」分頁，做三件事：
① 捲到最下面「Channel access token」按「Issue（發行）」→ 出現一大串字 → 複製貼到記事本，標記為 🔑A。
② 「LINE Official Account features」區：把「自動回覆訊息」和「加入好友的歡迎訊息」都停用（點 Edit 進去關）。
③ 用手機 LINE「加入好友 → 行動條碼」掃這頁的 QR Code，把機器人加為好友。

第 2 關：建立試算表、貼上程式（＝機器人的大腦）

1
開 sheets.google.com（建議用個人 Gmail，學校帳號可能被管理員限制）→ 按「＋」建新試算表 → 左上角把名稱改成 LINE小幫手資料。
2
上方選單「擴充功能 → Apps Script」→ 會開一個程式編輯器。
3
先開啟本站的程式檔（會顯示一整頁文字）：
（載入中…）
在那頁按 Ctrl＋A 全選 → Ctrl＋C 複製。
4
回到 Apps Script 編輯器：把裡面原本那幾行 function myFunction()... 全選刪掉 → Ctrl＋V 貼上 → Ctrl＋S 儲存。
✔ 檢查：左側捲到最底，行數約 1,200 行、最後一行是單獨的「}」。若只有兩三百行代表沒複製完整，重做一次。
5
編輯器上方有個函式下拉選單（在「執行／偵錯」旁邊）→ 選 setupLineBot → 按「執行」。
第一次會跳出授權：選你的帳號 → 看到「Google 尚未驗證這個應用程式」不用怕（因為這程式是你自己貼的）→ 點小字「進階」→「前往…（不安全）」→「允許」。
6
下方「執行紀錄」會列出三串金鑰，全部複製到記事本：
・Webhook 驗證參數 ＝ 🔑B
・工作台同步金鑰 ＝ 🔑C
・教室大屏金鑰 ＝ 🔑D

第 3 關：把鑰匙插進去（指令碼屬性）

1
Apps Script 左側點齒輪「專案設定」→ 捲到最下面「指令碼屬性」→「新增指令碼屬性」，逐筆加入：
屬性（照抄）值
LINE_CHANNEL_ACCESS_TOKEN貼 🔑A（第 1 關那串最長的）
GEMINI_API_KEY選填。到 Google AI Studio 免費申請。不填也能用，但語音、照片、自然語言分類會停用
按「儲存指令碼屬性」。（還有一個 LINE_ALLOWED_USER_IDS 留到第 6 關。）

第 4 關：部署（＝把機器人開機）

1
右上「部署 → 新增部署」→ 點左邊齒輪 ⚙ 選「網頁應用程式」。
2
設定兩項：執行身分「我」、具有存取權的使用者「任何人」（⚠ 一定要選任何人，安全由亂數金鑰把關）→ 按「部署」。
3
複製產生的「網頁應用程式 URL」（https://script.google.com/macros/s/…/exec 結尾）＝ 🌐 你的機器人網址，存到記事本。
✔ 檢查：把這網址貼到瀏覽器打開，看到 {"ok":true,…} 就代表機器人活著。
🔁 以後更新程式：要用「部署 → 管理部署 → ✏️ 編輯 → 版本選『新版本』→ 部署」，網址才不會變。

第 5 關：接上 LINE（Webhook）

1
回 LINE Developers 的「Messaging API」分頁，找到「Webhook URL」→ 按 Edit，貼上：
🌐你的機器人網址?hook=🔑B
（把兩段接起來、中間不能有空格。例：https://script.google.com/macros/s/AKfy…/exec?hook=a1b2c3…）
2
開啟「Use webhook」開關 → 按「Verify」→ 顯示 Success ✅。
3
🎉 見證時刻：用手機對機器人傳「說明」→ 它會回你一整段使用說明。有回話就是全線打通了！

第 6 關：鎖門（只聽你的話）

1
對機器人傳「我的ID」→ 它回一串 U 開頭的字 → 複製。
2
回 Apps Script「指令碼屬性」新增：屬性 LINE_ALLOWED_USER_IDS、值＝那串 U 開頭的字。從此陌生人加這個機器人都不會有任何反應。

第 7 關：設定自動化（執行一個函式就好）

1
Apps Script 編輯器上方函式選單改選 setupTriggers → 按「執行」→ 完成！自動建立三個排程：每日簡報（每天 8–9 點）、未點名提醒（8:20 起智慧檢查）、每週家長關懷（週五下午）。

最後：把工作台接上機器人

1
回工作台網頁 →「⚙ 設定 → LINE 小幫手」→ 勾「啟用」→ 「🌐 Apps Script 部署網址」欄貼 🌐、「🔑C 同步金鑰」欄貼 🔑C（欄位上印著同樣符號，照符號貼就對了）→ 按「測試連線」→ 成功後按「立即同步」。
✅ 完成！教師工具箱會出現「LINE 收件匣」與「聯絡本」按鈕。用手機傳「明天要收回條」再按立即同步，收件匣就有東西了。

🅴 Part E：疑難排解

症狀解法
Webhook Verify 失敗網址結尾少了 ?hook=🔑B；或部署的存取權不是「任何人」
機器人已讀不回①「自動回覆訊息」沒關 ② Use webhook 開關沒開 ③ LINE_ALLOWED_USER_IDS 填錯（先清空該屬性測試）
貼程式時出現語法錯誤複製不完整。重開程式檔頁面 Ctrl+A 全選重貼，確認約 1,200 行
授權視窗一閃就關瀏覽器擴充功能擋掉了。改用無痕視窗（Ctrl+Shift+N）登入 Google 重做
工作台「測試連線」失敗🔑C 貼錯、網址不是 /exec 結尾、或改過程式忘了「新版本」重新部署
大屏送出失敗教室金鑰 🔑D 貼錯，或班級名稱空白
語音／照片沒反應沒填 GEMINI_API_KEY
換了電腦資料不見資料存在各電腦的瀏覽器裡。回舊電腦「下載 JSON 備份」→ 新電腦「從備份還原」
學校帳號部署被擋改用個人 Gmail 重做 Part B 第 2～4 關

🅵 Part F：備份與安全（給自己的保險）

  • 每週一次：工作台「設定 → 備份與還原 → 下載 JSON 備份」（不含金鑰，可安心存隨身碟）。
  • 4 把金鑰的家：🔑A 在 LINE Developers、🔑B🔑C🔑D 在 Apps Script 執行 setupLineBot 隨時可再看。金鑰與機器人網址不要貼到公開網頁或群組。
  • 權限分層：教室電腦只放 🔑D（只能回報當天）；🔑C（老師金鑰，可查歷史）只放自己的電腦與手機。
  • 試算表就是雲端備份：點名、作業、聯絡本的歷史都在你自己 Google 帳號的試算表裡，隨時打開看得到。
  • 大屏只使用座號，不輸入學生姓名；遲到紀錄只有老師在 LINE 與統計看得到，大屏畫面不顯示。
