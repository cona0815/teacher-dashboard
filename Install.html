📖 安裝教學（新手版）

從零開始，一步一步把「教師工作台＋LINE 小幫手＋晨間大屏」全部設定好。照著做就會，不需要任何程式基礎。

還在考慮要不要用？先看一頁式功能介紹，那頁也適合直接轉給同事。

先看這裡 A. 工作台 B. LINE 小幫手 C. 晨間大屏 D. 每天怎麼用 🔄 系統更新 E. 疑難排解 F. 備份與安全 版權

🧭 先看這裡：整套系統有三層，用多少裝多少

層級要裝什麼能做什麼
① 工作台網頁什麼都不用裝，開網址就能用任務清單、日曆、教學進度排課、記事、JSON 備份
② 晨間大屏需要先完成 B（因為要雲端同步）教室電腦點名、收作業、黑板聯絡本、統計報表
③ LINE 小幫手照本頁 B 部分部署一次（約 40–60 分鐘，只做一次）LINE 傳文字／語音／照片建任務、寫聯絡本、每日簡報、家長訊息草稿
會用到的名詞（先有個印象就好）：
・Google 試算表＝像 Excel 的雲端表格，當作 LINE 訊息的「轉運倉庫」。
・Apps Script（GAS）＝Google 提供的免費小程式空間，我們把「機器人的大腦」貼進去。
・金鑰＝一長串亂碼，功能像鑰匙：拿到鑰匙的人才能開門。本系統必要的有 4 把＋1 個網址，另有 1 把選用的 AI 金鑰（🔑E），全部用下面的符號標記。請把每一把都存進記事本並標上符號，之後每個要貼的欄位上都印著同樣符號，照著貼就對了。
🗝 符號對照表（超重要！設定畫面的欄位上印著一模一樣的符號，照著貼就對了）：
符號這是什麼哪裡取得貼到哪裡
🔑AChannel access tokenPart B 第 1 關，LINE Developers 按 Issue 發行Apps Script「指令碼屬性」的 LINE_CHANNEL_ACCESS_TOKEN（第 3 關）
🔑BWebhook 驗證參數Part B 第 2 關，執行 setupLineBot 後的「執行紀錄」（隨時可再執行查看）接在機器人網址後面：🌐?hook=🔑B（第 5 關）
🔑C工作台同步金鑰（老師專用，可查歷史）工作台「⚙ 設定 → LINE 小幫手 → 🔑C 同步金鑰」欄；大屏「查詢統計」也用這把
🔑D教室大屏金鑰（教室專用，只能報當天）大屏「⚙ 設定 → 🔑D 教室大屏金鑰」欄（教室電腦只放這把）
🌐機器人網址（/exec 結尾）Part B 第 4 關，部署後產生的網頁應用程式 URL工作台與大屏的「🌐 Apps Script 部署網址」欄，以及第 5 關的 Webhook URL
🔑EAI 金鑰（選用，Gemini API）Google AI Studio 免費申請兩處共用同一把：Apps Script「指令碼屬性」的 GEMINI_API_KEY（第 3 關，讓 LINE 能聽語音、看照片）＋工作台「⚙ 設定 → AI 設定 → 🔑E API 金鑰」欄（開啟 AI 行政助理）
💰 費用：全部免費。LINE 官方帳號免費方案＋Google 免費額度就夠用。唯一的量限制：LINE「主動推播」每月 200 則（每日簡報一天 1 則，一個月才用 30 則，很夠）。

🅱 Part B：部署 LINE 小幫手（40–60 分鐘，一生只做一次）

做完這部分，你會擁有一個「只聽你的話」的 LINE 機器人。過程有 7 關，每一關都很短。

第 1 關：建立 LINE 官方帳號（＝機器人的身體）

1
用電腦開 developers.line.biz/console，點「Log in with LINE account」，用你手機 LINE 的帳號密碼登入（手機 LINE →設定→帳號 可以確認/設定 Email 登入）。
2
按「Create a new provider」，名稱隨便打（例：我的教師工具）→ Create。
3
按「Create a Messaging API channel」。若它要求先建官方帳號：到 manager.line.biz 建立（免費），名稱例如「班級小幫手」，建好後進該帳號「設定 → Messaging API」按啟用，再回來。
4
進入 channel 的「Messaging API」分頁，做三件事：
① 捲到最下面「Channel access token」按「Issue（發行）」→ 出現一大串字 → 複製貼到記事本，標記為 🔑A。
② 「LINE Official Account features」區：把「自動回覆訊息」和「加入好友的歡迎訊息」都停用（點 Edit 進去關）。
③ 用手機 LINE「加入好友 → 行動條碼」掃這頁的 QR Code，把機器人加為好友。

第 2 關：建立試算表、貼上程式（＝機器人的大腦）

1
開 sheets.google.com（建議用個人 Gmail，學校帳號可能被管理員限制）→ 按「＋」建新試算表 → 左上角把名稱改成 LINE小幫手資料。
2
上方選單「擴充功能 → Apps Script」→ 會開一個程式編輯器。
3
先開啟本站的程式檔（會顯示一整頁文字）：
（載入中…）
在那頁按 Ctrl＋A 全選 → Ctrl＋C 複製。
4
回到 Apps Script 編輯器：把裡面原本那幾行 function myFunction()... 全選刪掉 → Ctrl＋V 貼上 → Ctrl＋S 儲存。
✔ 檢查：左側捲到最底，行數約 1,600 行、最後一行是單獨的「}」。若只有兩三百行代表沒複製完整，重做一次。
5
編輯器上方有個函式下拉選單（在「執行／偵錯」旁邊）→ 選 setupLineBot → 按「執行」。
第一次會跳出授權：選你的帳號 → 看到「Google 尚未驗證這個應用程式」不用怕（因為這程式是你自己貼的）→ 點小字「進階」→「前往…（不安全）」→「允許」。

・教室大屏金鑰 ＝ 🔑D

第 3 關：把鑰匙插進去（指令碼屬性）

1
Apps Script 左側點齒輪「專案設定」→ 捲到最下面「指令碼屬性」→「新增指令碼屬性」，逐筆加入：
屬性（照抄）值
LINE_CHANNEL_ACCESS_TOKEN貼 🔑A（第 1 關那串最長的）
GEMINI_API_KEY貼 🔑E（選填。到 Google AI Studio 免費申請，記事本標為 🔑E。不填也能用，但語音、照片、自然語言分類會停用；同一把之後也貼進工作台「AI 設定」開啟 AI 行政助理）
按「儲存指令碼屬性」。（還有一個 LINE_ALLOWED_USER_IDS 留到第 6 關。）

第 4 關：部署（＝把機器人開機）

1
右上「部署 → 新增部署」→ 點左邊齒輪 ⚙ 選「網頁應用程式」。
2
設定兩項：執行身分「我」、具有存取權的使用者「任何人」（⚠ 一定要選任何人，安全由亂數金鑰把關）→ 按「部署」。
3
複製產生的「網頁應用程式 URL」（https://script.google.com/macros/s/…/exec 結尾）＝ 🌐 你的機器人網址，存到記事本。
✔ 檢查：把這網址貼到瀏覽器打開，看到 {"ok":true,…} 就代表機器人活著。
🔁 以後更新程式：要用「部署 → 管理部署 → ✏️ 編輯 → 版本選『新版本』→ 部署」，網址才不會變。

第 5 關：接上 LINE（Webhook）

1
回 LINE Developers 的「Messaging API」分頁，找到「Webhook URL」→ 按 Edit，貼上：
🌐你的機器人網址?hook=🔑B
（把兩段接起來、中間不能有空格。例：https://script.google.com/macros/s/AKfy…/exec?hook=a1b2c3…）
2
開啟「Use webhook」開關 → 按「Verify」→ 顯示 Success ✅。
3
🎉 見證時刻：用手機對機器人傳「說明」→ 它會回你一整段使用說明。有回話就是全線打通了！

第 6 關：鎖門（只聽你的話）

1
對機器人傳「我的ID」→ 它回一串 U 開頭的字 → 複製。
2
回 Apps Script「指令碼屬性」新增：屬性 LINE_ALLOWED_USER_IDS、值＝那串 U 開頭的字。從此陌生人加這個機器人都不會有任何反應。

第 7 關：設定自動化（執行一個函式就好）

1
Apps Script 編輯器上方函式選單改選 setupTriggers → 按「執行」。
自動建立 4 個排程：每日簡報備援（8–9 點，預設關閉）、未點名提醒（8:20 起智慧檢查）、下午整合推播（16–17 點，三項功能共用，預設全關）、每週家長關懷（週五下午）。
⚠️ 若這是「更新程式碼後」再執行，會跳出授權畫面（因為新版要用到雲端硬碟備份功能）→ 一樣點「進階 → 前往…（不安全）→ 允許」即可。
2
🎉 驗收：用手機對機器人傳「推播設定」

成功的話它會回覆一份清單，長這樣：

📢 推播設定
本月推播已用 12／200 則

✅ 點名推播｜早上出缺＋今日課程／任務／記事／逾期
✅ 作業推播｜收完作業後的點名＋各科繳交情況
✅ 未點名提醒｜當天沒收到大屏回報才發
✅ 週五家長關懷｜缺交達門檻的家長訊息草稿
⬜ 每日簡報備援｜沒在用大屏的人才需要
⬜ 早期缺交預警｜同一科連續缺交就提早通知
⬜ 到期前一天提醒｜明天到期的任務先提醒
⬜ 放學小結｜下午回顧今天並提醒明天

看到這 8 項與本月用量，就代表全部設定成功了。✅ 是開啟、⬜ 是關閉；想調整就傳「開啟 放學小結」或「關閉 作業推播」。

沒回應？請檢查：① 程式碼是否貼完整並存檔 ② 是否已重新「部署 → 管理部署 → 新版本」 ③ LINE_ALLOWED_USER_IDS 是否填了你自己的 ID。

最後：把工作台接上機器人

1
回工作台網頁 →「⚙ 設定 → LINE 小幫手」→ 勾「啟用」→ 「🌐 Apps Script 部署網址」欄貼 🌐、「🔑C 同步金鑰」欄貼 🔑C（欄位上印著同樣符號，照符號貼就對了）→ 按「測試連線」→ 成功後按「立即同步」。
✅ 完成！教師工具箱會出現「LINE 收件匣」與「聯絡本」按鈕。用手機傳「明天要收回條」再按立即同步，收件匣就有東西了。

下方「訂正統計」三種看法：依座號（誰身上還有幾筆）→按科目（科目 → 進度兩層，點進度旁的 ▲ 直接跳到上面的版面）→日曆（哪一天還沒清完）。統計是近 30 天、跨日累計，不是只有今天。

📢 LINE 額度怎麼算？
LINE 免費方案的則數只算「小幫手主動推播」；你問它答完全免費、無上限。
會用到額度的只有：點名推播、作業推播、未點名提醒、週五家長關懷，以及預設關閉的 每日簡報備援、早期缺交預警、到期前一天提醒、放學小結。
在 LINE 傳「推播設定」可看到 8 項開關與本月真實用量（這也是安裝或更新後的驗收指令）， 傳「開啟 放學小結」「關閉 作業推播」即可切換。 用量接近上限時，系統會自動只保留點名推播，不會突然爆量。
⚠️ 額度是按收件人計算：若把兩支手機或同事的 ID 都加進 LINE_ALLOWED_USER_IDS，用量會加倍。
☁️ LINE 檔案自動備份（解決檔案過期）
傳給小幫手的照片與檔案（含轉傳的），會在收到當下自動存進你自己的 Google 雲端硬碟， 回覆訊息裡附上連結。以後 LINE 對話裡的檔案過期也不怕。
而且會自動分類命名：AI 讀完內容後，把檔案改成看得懂的名字，並歸到對應資料夾—— LINE小幫手備份／2026-08／會議與晨會／0828_第二次返校日晨會報告事項.jpg
分類有：通知單與回條、學生與親師、會議與晨會、公文與行政、課程與教材、活動與競賽、其他。
試算表會多一個「檔案備份」分頁當索引；在 LINE 傳「找檔案 晨會」就能找出檔案與連結。
可在「指令碼屬性」自訂：
屬性說明
DRIVE_BACKUP_FOLDER_ID想存到指定資料夾就貼該資料夾 ID（從網址列複製）；不填會自動建立「LINE小幫手備份」
DRIVE_BACKUP_TYPES要備份的類型，預設 image,file（照片與檔案）。想連影片一起備份就填 image,file,video；填 off 完全停用
DRIVE_BACKUP_MAX_MB單檔上限，預設 20（MB）
CLASS_NOTES代課包裡要附上的班級注意事項（選填）
⚠️ 此功能需要雲端硬碟權限：更新程式碼後第一次執行會再跳一次授權，照第 2 關第 5 步的方式允許即可。備份會佔用你 Google 帳號的免費容量（與 Gmail 共用 15GB）。

🔄 系統更新（已經裝好的老師才需要看）

還沒裝過 LINE 小幫手的老師請跳過這一段，直接照上面的 Part B 從第 1 關做起就好。
這一段是給已經完成部署、想要換上新版程式的老師用的，約 5 分鐘。

網頁部分（工作台、大屏、本教學）會自動更新，不用做任何事；只有 LINE 小幫手的 Google 程式需要手動換新版。

1
取得最新程式碼

開啟本站的程式檔（會顯示一整頁文字）→ 在那頁按 Ctrl＋A 全選 → Ctrl＋C 複製。

（載入中…）
2
貼進 Apps Script

開你的試算表 →「擴充功能 → Apps Script」→ 把裡面舊的程式碼全部刪掉 → Ctrl＋V 貼上 → Ctrl＋S 存檔。

✔ 檢查：捲到最底，行數約 1,600 行、最後一行是單獨的「}」。只有兩三百行代表沒複製完整，重做一次。

3
執行 setupTriggers（順便完成新權限授權）

函式選單選 setupTriggers → 按「執行」。

若跳出授權畫面（新版用到新權限時會跳，例如雲端硬碟備份功能）→ 選你的帳號 →「進階」→「前往…（不安全）」→「允許」。這是因為程式是你自己貼的，Google 一律會這樣提醒。

4
重新部署（關鍵！網址才不會變）

部署 → 管理部署 → ✏️ 編輯 → 版本選「新版本」→ 部署。

⚠️ 一定要用「管理部署 → 編輯 → 新版本」。若用「新增部署」會產生不同的網址，工作台與大屏就連不上了，還要重新設定。
5
🎉 驗收

用手機對機器人傳「推播設定」，看到 8 項開關與本月用量就代表更新成功。

沒回應？① 程式碼是否貼完整並存檔 ② 是否漏了第 4 步的「新版本」重新部署 ③ 舊版指令（今日點名、說明）是否還有回應——若舊指令也沒反應，多半是程式碼沒貼完整。

✅ 更新完成。原本的資料、金鑰、設定都會保留，不需要重設；試算表也不會被覆蓋。

🅵 Part F：備份與安全（給自己的保險）

  • ☁️ 雲端備份（有裝 LINE 小幫手才有）：工作台「設定 → 備份與還原 → 立即雲端備份」，把任務、教學進度、記事、設定整份存進你自己的試算表（分頁「工作台備份」），保留最近 10 份，預設每天開啟工作台時自動備份一次。換電腦時按「查看雲端備份」挑一份「還原這份」即可。
  • 每週一次：工作台「設定 → 備份與還原 → 下載 JSON 備份」（不含金鑰，可安心存隨身碟）。這是不依賴任何服務的離線保險。
  • ⚠️ 重要觀念：工作台的任務與教學進度平常只存在「這台電腦的這個瀏覽器」。就算裝好 LINE 小幫手也一樣——試算表裡的「工作台快照」只是給 LINE 簡報用的摘要（今日任務前 20 筆、逾期前 10 筆），不是備份、不能還原。真正能還原的只有上面兩種備份。
  • 金鑰的家：🔑A 在 LINE Developers、🔑B🔑C🔑D 在 Apps Script 執行 setupLineBot 隨時可再看、🔑E 在 Google AI Studio。金鑰與機器人網址不要貼到公開網頁或群組。
  • 權限分層：教室電腦只放 🔑D（只能回報當天）；🔑C（老師金鑰，可查歷史）只放自己的電腦與手機。
  • 試算表就是雲端備份：點名、作業、聯絡本的歷史都在你自己 Google 帳號的試算表裡，隨時打開看得到。
  • 大屏只使用座號，不輸入學生姓名；遲到紀錄只有老師在 LINE 與統計看得到，大屏畫面不顯示。
